# The Excuse That Almost Works

The single line a gamer texts the boss to skip work on GTA 6 launch week:

> Sorry, my car's been clamped and the release office doesn't open till Friday, working from home today.

A mundane, specific, almost-believable snag — a clamped car and a release office closed till Friday — with the car trouble as a quiet GTA wink. It reads like a real text sent in a hurry: plain words, no setup, no explanation, no signature. A tired manager who has heard every excuse twice would almost buy it.

The program (`main.ts`) validates the line (1–140 characters, at most 20 words, single line) and writes it to `entry.txt`.
